# trell0

minimalist productivity tool

## features

- move nodes
- edit nodes
- color nodes
- slick animations
- localStorage auto-save
- dark mode
- import/export (json)

## planned features

- keyboard shortcuts
- drag-select and multi-node actions
- undo/redo history
- tags and filters
- due dates
- markdown support in node content
- realtime collaboration
- mobile responsive layout
